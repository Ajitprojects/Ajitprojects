# CleanYourTab Home · v1 test

The original v1 opened on the Xiaomi Pad 7. Pressing Home returned to Xiaomi Home. This snapshot carries the updated public name.

Start with [MainActivity.java](app/src/main/java/com/gathin/cleanyourtab/MainActivity.java) for the launcher implementation and [AndroidManifest.xml](app/src/main/AndroidManifest.xml) for how Android discovers the activity.

Open this version’s folder as a separate Android Studio project. It targets Android SDK 35 with Java 17 source compatibility. See the [device test and version comparison](../README.md) for the original setup results.
